## 速度到底有多快？

说了这么多功能，最关键的还是速度。

我看到一个用户的测试数据：46MB的视频，上传只用了4秒，平均速度12MB/s；下载速度7MB/s。这个速度在文件传输服务里算是顶级的了。

为什么这么快？

**1. 全球服务器部署**  
Filemail在美国、欧洲、亚洲都有服务器，系统会自动选最近的那台，减少传输距离。

**2. UDP传输加速**  
Pro套餐及以上可以用桌面客户端，启用UDP传输加速协议。这个技术比传统的TCP传输快很多，特别是在网络不稳定的时候。

**3. 断点续传**  
万一网络中断了，不用从头开始，可以从断开的地方继续传。这对于传大文件来说太重要了，能省下大把时间。

## 安全性：不只是说说而已

Filemail在安全方面做得很到位。

所有文件传输都采用TLS-1.2（AES-256）加密。什么意思？就是传输过程中，即使被人截获，也看不到文件内容。

每个上传的文件都会进行病毒和恶意软件扫描。病毒库每周更新，确保能拦截最新的威胁。

服务器是Filemail自己的，不是租用别人的。而且有24小时现场安保人员监管。从2008年到现在，Filemail从来没被黑客攻破过，也没发生过数据泄露。
